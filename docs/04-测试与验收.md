## 4. 性能观测（DEMO 模式）

| 指标 | 数值 |
| --- | --- |
| DEMO 输出帧率 | ≈ 15 FPS（2 路，CPU） |
| MJPEG 单路带宽 | 约 3–6 Mbps（960×540，JPEG 72） |
| 告警落库到前端弹窗 | < 1 s（本机） |
| 后端接口响应 | 本机通常在 50 ms 内（H2） |
| 真实 YOLO（PPE + COCO，MPS） | 约 10 FPS，单帧推理约 90–140 ms |
| 真实 YOLO 检测 | 单帧 13 人 + 14 个 PPE 目标（示例视频） |

> Mock 模式不代表真实算法性能；真实 YOLO 的 FPS / mAP 需在目标机器上重新测量并填入论文。

## 6. 已知问题

| 问题 | 影响 | 处理 |
| --- | --- | --- |
| DEMO 模式为合成画面 | 不能代表真实精度 | 答辩前切换真实权重与视频源 |
| 浏览器摄像头未接入 | 少一种视频源 | 当前支持 RTSP / 文件 / USB / DEMO |
| 模型热切换未实现 | 需重启算法服务 | 后续可加 `/ai/models/active` |
| 大屏未嵌入实时视频 | 以图表为主 | 可扩展 MJPEG 视频窗格 |
| Docker 路径未在本机验证 | 容器构建存在环境差异风险 | 首次部署预留构建时间，按需调整基础镜像 |
