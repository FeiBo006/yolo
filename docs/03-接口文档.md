# 接口文档（v1.0）

- 后端 Base URL：`http://localhost:8080`
- 算法服务 Base URL：`http://localhost:8000`
- 前端开发代理：`/api` → 8080，`/ai` → 8000，`/ws` → 8080
- 时间格式：`yyyy-MM-dd HH:mm:ss`
- 认证方式：`Authorization: Bearer <JWT>`

## 1. 统一返回体

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 400 | 参数错误 / 业务校验失败 |
| 401 | 未登录 / Token 失效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务异常 |

分页数据：

```json
{
  "records": [],
  "total": 92,
  "page": 1,
  "size": 10
}
```

## 2. 认证

### POST /api/auth/login

```json
{ "username": "admin", "password": "123456" }
```

响应：

```json
{
  "code": 0,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": {
      "id": 1,
      "username": "admin",
      "realName": "系统管理员",
      "roleCode": "ADMIN",
      "status": 1
    }
  }
}
```

### GET /api/auth/me

返回当前用户。

### POST /api/auth/logout

将当前 Token 写入黑名单（内存或 Redis）。

## 3. 用户（ADMIN）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/users?keyword=&page=1&size=10` | 分页 |
| POST | `/api/users` | 新增，密码默认 123456 |
| PUT | `/api/users/{id}` | 修改，密码留空不改 |
| DELETE | `/api/users/{id}` | 逻辑删除，admin 不可删 |

## 4. 工地

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| GET | `/api/sites?keyword=` | 登录用户；地址已脱敏 |
| GET | `/api/sites/{id}` | ADMIN / MANAGER；返回完整地址，用于编辑 |
| POST | `/api/sites` | ADMIN / MANAGER |
| PUT | `/api/sites/{id}` | ADMIN / MANAGER |
| DELETE | `/api/sites/{id}` | ADMIN |

## 5. 摄像头

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/cameras?siteId=&keyword=` | 含 `siteName`、`online` |
| POST | `/api/cameras` | 新增 |
| PUT | `/api/cameras/{id}` | 修改 |
| DELETE | `/api/cameras/{id}` | 删除 |
| POST | `/api/cameras/{id}/test` | 调用算法服务探测视频源 |

请求体：

```json
{
  "siteId": 1,
  "cameraName": "1 号塔吊全景",
  "streamType": "RTSP",
  "streamUrl": "rtsp://admin:pass@192.168.1.10:554/stream1",

```

`streamType`：`DEMO` / `RTSP` / `VIDEO` / `USB`。

## 8. 告警

### GET /api/alarms

| 参数 | 说明 |
| --- | --- |
| status | PENDING / CONFIRMED / REPAIRED / FALSE_ALARM |
| behaviorType | 行为类型 |
| cameraId | 摄像头 |
| keyword | 摄像头名称 / 告警编号 |
| start / end | `yyyy-MM-dd HH:mm:ss` |
| page / size | 分页 |

### GET /api/alarms/{id}

详情。

### PUT /api/alarms/{id}/handle

```json
{ "status": "REPAIRED", "remark": "现场已整改，工人补戴安全帽" }
```

响应包含更新后的告警，同时通过 WebSocket 广播 `ALARM_UPDATE`。

### GET /api/alarms/export

参数同列表，返回 `xlsx` 文件流（最多 5000 条）。

## 10. WebSocket

- 地址：`ws://localhost:8080/ws/alarms?token=<JWT>`
- 客户端每 25 秒发送 `ping`，服务端回 `{"type":"PONG"}`

连接成功：

```json
{ "type": "CONNECTED", "message": "ok" }
```

新告警：

```json
{
  "type": "ALARM",
  "data": {
    "id": 49,
    "alarmNo": "1-1792829964478-1-NO_HELMET",
    "cameraId": 1,
    "cameraName": "1 号塔吊全景",
    "behaviorType": "NO_HELMET",
    "level": "HIGH",
    "confidence": 0.90,
    "trackId": 1,
    "bbox": "0.469,0.515,0.508,0.570",
    "snapshotUrl": "/ai/snapshots/1_1792829964_1_NO_HELMET.jpg",
    "alarmTime": "2026-10-24 16:19:24",
    "status": "PENDING"
  }
}
```

处置更新：`{"type":"ALARM_UPDATE","data":{...}}`。

## 13. curl 示例

```bash
# 登录
TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"123456"}' | jq -r '.data.token')

# 摄像头
curl http://localhost:8080/api/cameras -H "Authorization: Bearer $TOKEN"

# 告警
curl "http://localhost:8080/api/alarms?page=1&size=10&status=PENDING" \
  -H "Authorization: Bearer $TOKEN"

# 处置
curl -X PUT http://localhost:8080/api/alarms/49/handle \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"status":"REPAIRED","remark":"已整改"}'

# 内部配置
curl http://localhost:8080/api/internal/config -H 'X-Internal-Token: yuanyu-internal-2026'
```
